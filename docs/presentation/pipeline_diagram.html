Figure 1. How one user’s data becomes a cited answer. (A) The worker pulls mail and calendar changes every 5 minutes; rules drop bulk mail before any model sees it, and code, not the model, settles dates, confidence and merges. Calendar changes update meetings in code only. (B) Uploaded meetings are transcribed and extracted under the same rules. (C) Everything lands in one PostgreSQL store behind per-user row-level security (RLS). (D) A question is answered from a packet assembled mostly in code: vector (HNSW) and full-text results are fused by reciprocal rank fusion (RRF), and every claim is checked before it is shown. (E) No step calls a model directly.
